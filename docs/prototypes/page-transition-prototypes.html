Page-transition prototypes · StaticBlaze

Two approaches, built side by side as the comparison record. The rejected one stays here so the decision is reviewable. Chrome/Edge/Firefox; the JS is vanilla, no dependencies.

Approach A — full-window wiperejected

Page one

The whole window — chrome included — wipes away and the next document wipes in. Strong, but it breaks the persistent 3D background and header, so every navigation resets the "instrument".

Full coverage: the header and background are part of the wipe. Continuity is sacrificed for impact.
Approach B — partial blur (refocus)selected

Page one

Only the content refocuses: it blurs, shrinks and fades out, then the next page resolves in crisp. The header and the 3D background never move, so the site reads as one continuous instrument.

Partial coverage: chrome stays put, content does a depth "focus pull". Continuity is the point.
